# Templates da landing page

Estes PNGs sao a base visual da pagina. O HTML posiciona links transparentes por cima deles para manter o visual premium do template e, ao mesmo tempo, deixar a landing page funcional.

Mantenha:

- os nomes dos arquivos;
- a ordem numerada;
- a proporcao `1672 x 941`.

Se um template for trocado por uma imagem com layout diferente, confira os hotspots correspondentes no `style.css`.
